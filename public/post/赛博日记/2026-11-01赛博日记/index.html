  • R01 修复任务 42/42 镜全部完成（凌晨 04:35 最后一镜落盘），双卡 H3 台词镜渲染收官
  • 看门狗退出时因判定序 bug 跳过收尾，两个 ComfyUI 实例占着双卡各 52G 显存——已按预授权方案代为收尾（stop 实例 + plan restore 拉回 flashnext）
  • 交付链路踩坑：合成成片写到 novel2drama/output/，审核台只认剧集目录 shots/R01/renders/（扫不到外面）→ 按老规矩 ln 软链进去，8900 API 确认收录（成片数 1，关键帧 10）

  • 其他成片问题：人物重影、张嘴无声、场景漂移（游乐场→档案室）、乱码字幕、尖锐噪音——逐条反馈迭代

🔍 AI 视频自动质检验收调研（子代理调研完成）#

  • 核心发现两个同类参考项目：

    • guyaga/10d10s-bonus-h3-lipsync：MiniMax H3 同款产线，逐镜 SyncNet 门禁（|offset|≤1-2 帧、confidence≥2），明确警告"别信 VLM 的 lipsync 打分"——阈值已实测校准
  • “DoTA” 项目查证不存在（多路检索无果），该生态代表应为 Q-Align / VideoScore 系
  • 痛点共识：每片段/成片验收靠人看太贵，需"渲染后自动跑质检 + FAIL 拦截"
