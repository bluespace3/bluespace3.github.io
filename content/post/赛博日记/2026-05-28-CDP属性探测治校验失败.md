## 🔍 核心技术进展

### 1. CDP DOM 属性探测 —— 解决「操作成功但校验失败」的根本问题
- **来源**：Cursor 会话（17:40，80 条消息）
- **根因**：自定义 `div` 复选框状态仅靠 `class` 变化体现，截图和 accessibility 树均不可靠。Agent 反复点击同一处，14 步空转。
- **方案**：新建 `probe_dom` 工具，通过 CDP 直接读取 `className`、`aria-checked`、`input.checked`，点击后自动触发 `[复选框探测]`，从被点击节点向上最多 16 层查找 `check-box` 容器。
- **泛化**：从最初需要用例手写 XPath，演化为全自动识别——点击成功后自动检测附近是否有复选框容器，无需用例做任何适配。判断标准统一为 `\bchecked\b`（独立 `checked` 词），覆盖 `check-box_checked` 和 `filterbar-checkbox checked` 两种页面风格。
- **文件**：`dom_probe.py`（新建）、`hover_extension.py`、`agent_runtime.py`

### 2. 点击意图守卫 —— 终结「提交订单」误点「营业执照」的死循环
- **来源**：同上 Cursor 会话
- **根因**：页脚链接和主 CTA 按钮在 `browser_state` 的 index 上混淆，Agent 选中 `index=59` 以为点的是「提交订单」，实际触发了页脚外链，误开新标签页后陷入 `switch_to_tab` 循环。
- **方案**：新增 `click_guard.py`，点击前用 CDP 读取目标元素的 tag、文案、是否在页脚区域，命中拦截条件直接阻止；点击后检测是否误开新标签页，自动纠错。
- **教训**：提示词里写了 CSS 选择器 `a.link` 被弱模型当成 URL `https://a.link/` 执行 `navigate`，导致整页跳转。**面向 LLM 的提示词不能包含任何可能被解析为 URL 的字面量**。

### 3. 标签筛选「通过」命中「未通过」—— 数据库查询语义的精准性
- **来源**：同上 Cursor 会话
- **根因**：正式服标签存储为 `["已整理，PC-AI自动化"]`（单元素内中文逗号拼接），`tags @> '["PC-AI自动化"]'::jsonb` 匹配不到 → `total: 0`。同时 LIKE 查询会让「通过」误匹配「未通过」。
- **决策**：查询改回 `@>` 精确匹配，数据通过重新导入规范化为 `["已整理", "PC-AI自动化"]`（每项一个标签）。
- **关键文件**：`test-cases.service.ts`、`test-case-tags.util.ts`

### 4. 用例库运行状态标签 + 测试报告优化
- **来源**：同上 Cursor 会话
- **实现**：用例库单条执行结束后自动写入「通过/未通过」标签，复用 `mergeTestCaseRunStatusTag`，与测试计划行为统一。
- **报告**：失败截图支持全屏放大（lightbox），报告缓存刷新逻辑修复（优先从服务端拉最新版）。

### 5. NSIS 覆盖安装快捷方式丢失 + EBUSY 打包失败
- **来源**：同上 Cursor 会话
- **根因（快捷方式）**：`customInit` 在安装前删了快捷方式，但 electron-builder 覆盖安装时 `keepShortcuts=true` + `isUpdated=true` 跳过重建。
- **修复**：`customInit` 只清 Squirrel 子目录，`customInstall` 强制覆盖桌面和开始菜单快捷方式。
- **根因（EBUSY）**：在线 Worker 复用缓存目录，上次构建/杀毒仍占用 exe → `unlink` 失败。
- **修复**：打包前 rename 到 `.trash` 再删，带重试。
- **提交**：`3cfc5df` — `fix: 修复 NSIS 覆盖安装后快捷方式失效`，已推 `dev/main`。

## 💡 深度洞察与经验教训

- **洞察**：Web 自动化测试的瓶颈往往不是「操作不成功」，而是「无法确认操作成功」。复选框问题的本质是 **校验链路与操作链路的不匹配** —— CDP 能点到，但模型只能靠截图猜。解决方案不是优化截图，而是 **换一条不依赖视觉的校验通道**（CDP DOM 属性）。这个思路可以推广到所有「视觉不可靠」的 UI 元素。

- **教训①**：**面向 LLM 的提示词是「代码」，不是「文档」**。`a.link` 被当成 URL 导致整页跳转，提醒我们提示词中的每一个字面量都需要做「模型会如何理解它」的安全审查，就像 SQL 注入防护一样。

- **教训②**：**数据格式不一致是定时炸弹**。本地 `["已整理", "PC-AI自动化"]` vs 正式服 `["已整理，PC-AI自动化"]`，测试环境一切正常，上线就炸。数据规范必须在写入层强制执行，不能依赖「导入时顺便修」。

- **教训③**：**跨 shell 脚本兼容性**。`set VAR=...&&` 在 cmd 有效但 PowerShell 下静默失败，改用 Node 脚本（`spawnSync('npm', [...], { shell: true })`）是最稳妥的方案。
